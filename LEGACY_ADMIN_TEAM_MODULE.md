# Старый модуль `/admin/team`

## Что это такое

`/admin/team` — старый раздел управления командой автошколы. Он создавался для работы с инструкторами и сотрудниками:

- создание профиля инструктора;
- создание учетной записи сотрудника;
- привязка сотрудника к инструктору;
- выдача, изменение и удаление доступа;
- сброс временного пароля;
- включение и отключение инструктора;
- управление отображением профиля в публичном списке;
- удаление демо-профилей.

## Текущее состояние

Страница `src/app/admin/team/page.tsx` сейчас сразу перенаправляет пользователя на `/admin`, поэтому старый интерфейс не показывается и в обычной работе не используется.

Файл `src/app/admin/team/actions.ts` полностью написан для Supabase и не содержит PostgreSQL-ветки. Если снова подключить старые формы или actions, они потребуют Supabase admin key и не будут работать в PostgreSQL-продакшене.

## Актуальная замена

Для управления сотрудниками сейчас используется раздел `/director/staff`. Он работает через PostgreSQL и предназначен для текущей версии системы.

## Решение

Сейчас код не менять. Модуль зафиксирован как технический долг. Позже нужно выбрать один вариант:

1. полностью перенести старые actions на PostgreSQL;
2. удалить старые actions и компоненты после проверки, что они больше нигде не подключаются.
