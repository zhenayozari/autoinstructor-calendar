# Отключённый модуль Admin Team

Этот каталог временно хранит старый модуль `/admin/team`.

## Почему он отключён

- маршрут `/admin/team` раньше перенаправлял на `/admin`;
- актуальное управление сотрудниками находится в `/director/staff`;
- старые формы и server actions не имели внешних импортов;
- старый модуль использовал Supabase и не относится к текущему PostgreSQL-runtime.

Исходники сохранены с расширением `.disabled`, поэтому Next.js и TypeScript их не собирают.
Удалять архив можно только после локальной проверки и отдельного коммита.
